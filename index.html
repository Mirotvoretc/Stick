Адрес игрового сервера

Если игра открыта с адреса Render, сервер подставится автоматически. Если игра открыта с GitHub Pages, укажи HTTPS-адрес Render. Физику матча рассчитывает сервер.

Адрес сохраняется на телефоне. У всех игроков должен быть одинаковый адрес.
