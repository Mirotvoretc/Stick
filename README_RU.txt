STICK ARENA — СЕРВЕРНАЯ ВЕРСИЯ 2.0
===================================

ЧТО ИЗМЕНЕНО
------------
1. Физика матча выполняется на сервере с фиксированным шагом 60 раз в секунду.
2. Телефоны отправляют только управление и получают состояние мира. Они больше не рассчитывают онлайн-урон, столкновения, снаряды и поведение боссов.
3. Сервер отправляет обновления мира 20 раз в секунду. Если телефон временно не успевает получать данные, сервер не накапливает бесконечную очередь старых снимков.
4. Комнаты имеют шестизначный код, максимум три игрока.
5. Игра и WebSocket-сервер обслуживаются одним Node.js-сервисом. Все игроки могут открыть один и тот же адрес Render; адрес сервера подставляется автоматически.
6. Серверные файлы: server.js, game-engine.js, package.json, render.yaml. Игровая страница: index.html.

БОССЫ
-----
Теневой владыка: теневой залп и направленный разрез. Его залп — фирменная атака, не общий шаблон для всех боссов.
Колосс: мощный прыжок с ударной волной и каменные снаряды. Ударная волна срабатывает после приземления.
Некромант: призывает зомби и выпускает веер духовных снарядов.
Электрический гигант: отмечает позицию игрока, затем бьёт молнией и разветвлёнными разрядами.

На 5-м уровне босса и выше при первом снижении здоровья ниже 50% проводится одна проверка:
- 5% — пробуждение: здоровье восстанавливается до 72% максимального, старые обычные атаки заменяются тремя усиленными атаками пробуждения;
- следующие 30% — режим ярости: скорость, темп атак и урон возрастают;
- остальные 65% — дополнительная фаза не включается.

У любого босса есть отдельный рывок: 20% шанс при проверке, если живой игрок находится впереди на подходящем расстоянии и босс не занят подготовкой/исполнением другой способности. После рывка действует перезарядка.

УСТАНОВКА С ТЕЛЕФОНА ЧЕРЕЗ GITHUB И RENDER
------------------------------------------
Компьютер не нужен. Все действия выполняются в браузере телефона.

1. Скачай ZIP-комплект и распакуй его на телефоне.
2. Открой свой репозиторий GitHub в браузере. Если мобильная версия сайта скрывает нужные кнопки, включи в браузере «Версия для ПК».
3. В корне репозитория замени/добавь эти пять файлов:
   index.html
   server.js
   game-engine.js
   package.json
   render.yaml
4. В GitHub выбери Add file -> Upload files, загрузи файлы из распакованной папки и сделай Commit changes.
5. Открой Render и создай новый Blueprint из этого GitHub-репозитория. Render должен прочитать render.yaml и создать Node web service.
6. Дождись успешного Deploy. Открой выданный Render URL — на нём будет сама игра и игровой сервер.
7. На первом телефоне нажми PLAY/ОНЛАЙН -> СОЗДАТЬ КОМНАТУ. Передай шестизначный код друзьям.
8. Остальные игроки открывают тот же Render URL, вводят код и подключаются.

ВАЖНО
-----
- В корне репозитория должны лежать все пять файлов рядом, не внутри отдельной папки.
- Не оставляй старый server.js или старый game-engine.js: они должны соответствовать index.html из этого комплекта.
- Если ты открываешь HTML через GitHub Pages, а не через Render, введи Render HTTPS URL в поле адреса сервера в меню Онлайн. Проще всем открывать Render URL напрямую.
- Комнаты и матчи хранятся в памяти процесса. После перезапуска/сна сервера активная комната завершится, её нужно создать заново.
- На бесплатном хостинге могут быть ограничения ресурсов или пробуждение после простоя. Для более стабильной задержки нужен сервер, который не засыпает, и близкий к игрокам регион.
- Нельзя гарантировать нулевую задержку на любых телефонах и сетях. Серверная физика убирает зависимость от FPS телефона хоста, но интернет-маршрут и качество сети всё ещё влияют на ping.
- Этот комплект подготовлен локально. Он не загружает файлы в твой GitHub автоматически: для замены файлов нужен вход в твой аккаунт и Commit changes.

ПРОВЕРКИ, ВЫПОЛНЕННЫЕ ПЕРЕД УПАКОВКОЙ
------------------------------------
- JavaScript-синтаксис всех встроенных скриптов index.html проверен Node.js.
- Синтаксис server.js и game-engine.js проверен Node.js.
- Серверный игровой движок запущен в тестовой среде: проверены матчи с двумя и тремя игроками, движение по входным данным и отдельные исходы проверок фаз босса.
- Полный сетевой запуск через публичный Render, реальное соединение двух физических телефонов и фактический ping из этой среды проверить нельзя. Для этого нужна публикация в твоём Render и тест на устройствах.
