STICK ARENA 2.4.2
================

ЧТО ИЗМЕНИЛОСЬ В ЭТОЙ ВЕРСИИ
---------------------------
- Сенсорное управление показывается только на смартфонах. На Windows/macOS/Linux и обычных ноутбуках панель скрыта, управление остаётся клавиатурным.
- Определение телефона больше не опирается только на наличие сенсорного экрана: проверяются мобильный User-Agent, наличие сенсорного ввода и размер экрана.
- Оружие перерисовано с металлическими деталями, бликами, прицелами и более читаемыми силуэтами; добавлены вспышки выстрелов.
- Переработаны зомби, элитные противники и боссы: броня, пластины, шипы, светящиеся элементы и отличающиеся силуэты.
- Метеориты и обвал получили каменную форму, кратеры, раскалённые трещины, хвост, искры и эффект удара.
- Снаряды, следы, частицы, ударные волны и HUD стали выразительнее.
- Рукопашник: шанс критического удара кулаками увеличен с 10% до 25% (урон ×3); успешное попадание имеет 15% шанс восстановить 3 HP. Перезарядка тарана уменьшена до 7 секунд; длительность самого рывка оставлена 0,9 секунды. Таран больше не пытается оглушать боссов.
- Рукопашник начинает восстанавливать здоровье после 11 секунд без полученного урона, затем получает 1 HP каждые 1,5 секунды.
- Прыжок игровых персонажей усилен: обычный прыжок 800, управляемый прыжок ботов 860. Навигация ботов допускает более высокие и широкие переходы между платформами.
- Максимальное здоровье всех боссов уменьшено ровно на 15% с учётом уровня и множителя количества игроков.
- Боссы реже прыгают возле стен и меньше застревают в циклах прыжков. Прыжок Колосса стал ниже и происходит реже.
- Исправлено прохождение врагов сквозь барьер Штурмовика при высокой скорости: столкновение теперь останавливает противника на первой пересечённой стороне.
- Призрак уклоняется от пуль и снарядов с вероятностью 15% вместо 7%.
- Радужная пушка наносит боссам на 50% больше периодического урона лучом; урон по обычным врагам не изменён.
- Дуэлянт отражает до трёх вражеских снарядов за 4 секунды после активации способности; метки врагов сохранены.
- Медик восстанавливает 10 HP каждые 12 секунд. Таймер работает равномерно и не выдаёт мгновенное лечение сразу после получения урона.
- Двойник: при первой смерти оригинала клон исчезает, оригинал переносится на его позицию и возвращается с 50% максимального здоровья.
- Берсерк теряет 1 HP в секунду во время ярости вместо 2 HP в секунду.
- Колосс получил более массивную каменную броню, шлем, наручи и светящиеся трещины.
- Добавлены тесты баланса, парирования, передачи тела Двойника, здоровья боссов и столкновения барьера.
- Главное меню, выбор режимов, карты, кнопки и сетевые панели получили единый стиль без разрозненных визуальных тем.
- В меню Онлайн кнопка проверки теперь делает WebSocket ping/pong и показывает примерный RTT до сервера.
- Добавлена бесплатная установка Node.js-сервера прямо на Android через Termux для игры по Wi-Fi. Для игры из разных сетей описан вариант частной виртуальной сети. Инструкция — README_HOSTING_ANDROID_RU.txt.
- Подготовлена установка на постоянно работающий VPS через Docker Compose и Caddy. Подробная инструкция — README_HOSTING_RU.txt.

СЕТЕВАЯ АРХИТЕКТУРА
-------------------
- Физика матча выполняется сервером с шагом 60 раз в секунду.
- Сервер отправляет состояние мира 20 раз в секунду.
- Клиент отправляет управление до 40 раз в секунду.
- В комнате может быть до трёх игроков.
- Кнопка «Создать комнату» не делает телефон хостом симуляции: матч рассчитывает сервер хостинга.
- Комнаты находятся в оперативной памяти. После перезапуска сервера активные комнаты завершатся.

КАКОЙ ХОСТИНГ ИСПОЛЬЗОВАТЬ
-------------------------
Для коротких бесплатных сессий сервер можно запустить на Android через Termux. Для круглосуточной публичной игры предпочтительнее постоянно работающий VPS/VDS в дата-центре с хорошим маршрутом до интернет-провайдеров игроков. В комплект добавлены Dockerfile, docker-compose.yml, Caddyfile и .env.example. Caddy выдаёт HTTPS-сертификат и проксирует WebSocket через WSS.

Провайдер, его текущую доступность, цены и маршруты из этой среды проверить нельзя. Не выбирай тариф только по названию или обещанию «низкого ping»: проверь соединение именно со своих устройств и сетей. Подробная пошаговая установка VPS находится в README_HOSTING_RU.txt, а Android-хостинга — в README_HOSTING_ANDROID_RU.txt.

ПРОВЕРКА ЗАДЕРЖКИ
-----------------
Открой меню «Онлайн», укажи HTTPS-адрес сервера и нажми «ПРОВЕРИТЬ ЗАДЕРЖКУ». Игра отправит серверу ping и измерит время до ответа pong. Это приблизительный RTT. Проверяй с каждого устройства и сравнивай несколько запусков на той же сети. Чем меньше и стабильнее результат, тем лучше маршрут до сервера.

УСТАНОВКА ОБНОВЛЕНИЯ В GITHUB
-----------------------------
1. Распакуй архив.
2. Загрузи содержимое папки Stick-main в корень репозитория, сохранив структуру папок.
3. Обязательно замени index.html, css/styles.css, js/core.js и js/online.js. Также загрузи остальные файлы проекта, включая server.js, game-engine.js, package.json, Dockerfile, docker-compose.yml, Caddyfile, .env.example и tests/.
4. Не создавай дополнительную вложенную папку: index.html и server.js должны находиться прямо в корне репозитория.
5. После публикации полностью закрой старые вкладки игры и открой обновлённую страницу заново.

ПРОВЕРКИ
--------
- `npm run check` пройден: синтаксис серверного, клиентского и тестового JavaScript проверен.
- `npm test` пройден: проверены движение двух игроков, игровые слоты, сетевые снимки, запуск босса, отрисовка оружия/врагов/метеоритов и условия показа сенсорного управления.

ПУБЛИКАЦИЯ САЙТА ЧЕРЕЗ GITHUB PAGES
-----------------------------------
Для публикации смотри README_GITHUB_PAGES_RU.txt. В версии 2.4.2 CSS и JavaScript подключаются относительными путями, поэтому работают внутри подпапки репозитория GitHub Pages.
