STICK ARENA — проект из нескольких файлов

КАК ЗАПУСТИТЬ
 ПК: откройте папку stick-arena и дважды щёлкните index.html (остальные файлы подтянутся сами).
 Телефон (Android): положите папку в память, откройте index.html через Chrome. Если файловый менеджер
 открывает его без подключения js/css, используйте stick-arena-single.html (всё в одном файле)
 или запустите мини-сервер:  python -m http.server 8080  (Termux/ПК) и откройте http://АДРЕС:8080

ФАЙЛЫ (разбиты по порядку кода; порядок подключения в index.html менять нельзя, 99-init.js всегда последний)
 index.html            — страница и подключение скриптов
 css/style.css         — оформление меню, телефонные стили
 js/01-config.js       — данные: классы, оружие, карты, боссы, настройки
 js/02-core.js         — ядро: сущности, урон, эффекты, статусы
 js/03-world-events.js — карты побольше, камера, летучая мышь, коллапс, радужная пушка
 js/04-map-events.js   — события на картах
 js/05-weapons.js      — стрельба, снаряды, физика, турели, стены
 js/06-ai-bosses.js    — боты, зомби, элитные враги, мини-боссы, боссы
 js/07-game-flow.js    — предметы, раунды, ход игры
 js/08-render.js       — отрисовка: стикмены, боссы, интерфейс боя
 js/09-ui-input.js     — меню, ввод, телефонное управление
 js/10-slime.js        — класс «Слизь», копирование, пассивки и сохранение разблокировки
 js/99-init.js         — запуск (должен идти последним)

КЛАСС «СЛИЗЬ»
 Разблокировка: убить 12 зомби одной атакой. Прогресс разблокировки хранится в localStorage отдельно для слотов игроков 1, 2 и 3 в текущем браузере.
 При очистке данных сайта или переходе в другой браузер/на другое устройство разблокировку потребуется получить снова; серверной синхронизации аккаунтов в этой статической версии нет.
