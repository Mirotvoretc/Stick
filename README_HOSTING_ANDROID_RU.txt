STICK ARENA 2.4.2 — ЗАПУСК ИГРОВОГО СЕРВЕРА С ANDROID

Главное: есть два разных сценария.

1) БЕСПЛАТНО ПО ОДНОЙ WI-FI-СЕТИ

Это самый простой способ проверить сервер с телефона. Игровая логика будет работать на телефоне, а друг сможет подключиться, если оба устройства в одной Wi-Fi-сети.

На телефоне-хосте:

1. Установи Termux из официального источника проекта Termux. Не используй устаревшую сборку Termux из Google Play.
2. Открой Termux и выполни:

   pkg update && pkg upgrade -y
   pkg install nodejs-lts unzip -y
   termux-setup-storage

3. Скачай архив Stick-Arena-2.4.2-Balance-Update.zip и положи его в папку Download телефона.
4. В Termux выполни:

   cd ~/storage/downloads
   unzip Stick-Arena-2.4.2-Balance-Update.zip
   cd Stick-main
   npm install
   npm start

5. Не закрывая Termux, открой в браузере телефона:

   http://127.0.0.1:8080

6. Чтобы друг открыл игру по Wi-Fi, узнай локальный IP телефона-хоста в настройках Wi-Fi. Обычно он выглядит как 192.168.x.x. Друг открывает:

   http://192.168.x.x:8080

Вместо примера нужно вставить настоящий локальный IP телефона-хоста. Хост тоже должен открыть игру через этот же IP, а не через 127.0.0.1, чтобы оба клиента автоматически использовали одинаковый адрес WebSocket.

2) БЕСПЛАТНО ИЗ РАЗНЫХ СЕТЕЙ — ЧЕРЕЗ ПРИВАТНУЮ СЕТЬ

Если друг находится в другом доме или городе, обычный Wi-Fi-адрес не подойдёт. Один из вариантов — установить приложение частной виртуальной сети (например, Tailscale) на телефон-хост и устройство друга. Оно должно подключить оба устройства к одной приватной сети. Условия бесплатного тарифа и доступность в конкретных странах/сетях проверяй перед настройкой: они меняются.

Порядок после подключения обоих устройств к одной приватной сети:

1. На телефоне-хосте Termux уже должен запускать игру командой npm start.
2. В приложении приватной сети найди IP телефона-хоста. Для Tailscale это адрес устройства внутри tailnet, обычно из диапазона 100.x.x.x.
3. На обоих телефонах открой один и тот же адрес: http://IP-ТЕЛЕФОНА-ХОСТА:8080.
4. Один игрок создаёт комнату, другой вводит код.
5. В меню «Онлайн» нажмите «Проверить задержку» с обоих устройств. Если RTT нестабилен или высокий, матч будет ощущаться с задержкой.

Если приватная сеть не соединяется из вашей страны или мобильного оператора, не пытайся обходить ограничения случайными прокси: лучше использовать легальный хостинг, доступный обоим игрокам.

КАК НЕ ДАТЬ ANDROID ОСТАНОВИТЬ СЕРВЕР

- Не закрывай Termux свайпом из списка последних приложений.
- Выполни в отдельной сессии Termux команду termux-wake-lock.
- В настройках Android исключи Termux из оптимизации батареи и разреши фоновую работу.
- Не включай режим энергосбережения во время матча.
- Следи за температурой телефона. Постоянная нагрузка и зарядка одновременно могут сильно нагревать устройство.
- Если Android всё равно выгружает Termux, телефон перестанет быть сервером и комнаты отключатся.

ЧЕГО НЕ ОБЕЩАЕТ ТЕЛЕФОННЫЙ ХОСТИНГ

- Это не круглосуточный дата-центр: экран может гаснуть, Android может завершить процесс, связь может пропасть.
- Мобильные операторы часто используют CGNAT, поэтому прямое подключение друзей через мобильный IP обычно не работает.
- Если друг подключается через VPN/overlay-сеть или туннель, задержка зависит от маршрута и relay-серверов.
- Нулевой ping не существует. Сначала замеряйте RTT, затем выбирайте способ размещения.

ЕСЛИ НУЖЕН ПОСТОЯННЫЙ ПУБЛИЧНЫЙ СЕРВЕР

Тогда сервер должен работать на VPS или другом постоянно доступном узле, а телефоны будут только клиентами. Бесплатный тариф, который одновременно поддерживает Node.js, WebSocket, постоянный процесс, публичный адрес и не усыпляет сервер, нельзя гарантировать. Проверь актуальные лимиты, регион и доступность хостинга из сети каждого игрока до переноса. Не оплачивай тариф, пока не проверишь RTT и подключение тестовой комнаты.

БЫСТРАЯ ПРОВЕРКА

1. Запусти сервер и открой игру на хосте.
2. Подключи второе устройство.
3. Создайте комнату и начните матч.
4. Если матч работает в Wi-Fi, но не работает из разных сетей, проблема уже не в боевой логике, а в доступе к серверу/NAT/туннеле.
5. Если оба игрока подключаются, но есть лаги, сравните RTT на обоих устройствах и проверь нагрузку телефона-хоста.
